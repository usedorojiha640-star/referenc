# BURO PAY — референсный вариант

Полностью самостоятельная вёрстка, вдохновлённая логикой и структурой ValutaEx: горизонтальная шапка, крупный оффер и калькулятор обмена, секции преимуществ, этапов сделки, географии и FAQ. Это не копия сайта.

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка для Cloudflare Pages

- Build command: `npm run build`
- Output directory: `dist`
- Production branch: `main`

## Настройки

В `src/App.jsx` замените `TELEGRAM` на ссылку менеджера. Сейчас она сохранена из предыдущего BURO PAY.

Калькулятор поддерживает USD, EUR, RUB, CNY, KZT, USDT, BTC, ETH; вкладки «Продать» и «Купить», конвертацию, город и создание Telegram-заявки. Числа в `RATES` — статические демонстрационные справочные значения, **не живые рыночные курсы** и не подтверждённые котировки. Для боевой эксплуатации подключите собственный источник актуальных курсов и расчёт комиссии.

Никаких обещаний о количестве офисов, бонусах, обязательной лицензии или доступности определённых стран не добавлено.
